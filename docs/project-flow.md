# FarmRent Project Flow

## 1. Project Overview

FarmRent is a web-based agricultural equipment rental platform designed to connect farmers who need equipment with equipment owners who want to make their equipment available for rental.

The platform provides equipment discovery, filtering, rental requests, user accounts, and rental management.

---

## 2. Main User Roles

FarmRent supports three primary roles:

### Farmer

A farmer can:

- Create an account
- Login
- Browse agricultural equipment
- Search equipment
- Filter equipment
- View equipment details
- Select rental dates
- Submit rental requests
- Track rental activity

### Equipment Owner

An equipment owner can:

- Create an owner account
- Login
- List agricultural equipment
- Provide equipment details
- Set rental price
- Manage equipment availability
- Review rental requests

### Administrator

An administrator can manage platform-level information such as:

- Users
- Equipment listings
- Rental requests
- Rental records
- Platform data
